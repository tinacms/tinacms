Update to `@tinacms/graphql` 4. Sign-in now needs a database client generated by the matching `@tinacms/cli`. Update `@tinacms/cli` with this package, then run `tinacms build` or `tinacms dev` to regenerate `tina/__generated__/databaseClient`. Self-hosted sites with an auth collection also need `authCollection.admins` to manage users from the admin.
